状態は、4つで足りる。

ノードを押すと、その状態に切り替わります。実際のキャラクターも上の画面で同時に変わります。

state machine / demo入力: pointer, keyboard
enter press release

※ノードはデモ用の操作盤です。実際の入力（ホバー・押下）でも同じ状態に切り替わります。

動きの前に、
状態の名前を決める。

「かわいく動かす」ではなく、「どの状態から、どの入力で、どこへ移るか」。先に決めると、動きは自然に短くなります。

01 / NAME

名前は動詞で

idle・hover・press。形容詞より、起きたことをそのまま書く。

02 / INPUT

入力を1つに絞る

同じ状態へ複数の入力が来ると、戻り方がわからなくなる。

03 / EXIT

戻り道を先に

release を必ず用意する。抜けられない状態を作らない。

状態は、そのまま渡せる

ノードと入力の対応を、設定として書き出します。実装側と言葉がずれません。

図に戻る 
// loop.state.json
{
  "idle":  { on: { hover: "hover" } },
  "hover": { on: { down:  "press",
               leave: "idle" } },
  "press": { on: { up:    "release" } },
  "release":{ after: "idle" }
}
