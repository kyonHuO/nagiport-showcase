# nagiport-showcase

Nagiport が制作した **サイト見本 45作品** の公開一覧です。

- 一覧: `index.html`（各作品へのリンク）
- 各作品: 独立した静的HTML 1ファイル（`01-lattice-figma.html` など45件）
- 公開: GitHub Pages（`main` ブランチ直下）

## 位置づけ

- すべて**架空の店舗・企業**を想定したデザイン見本です。実在の店舗・企業・人物・価格・実績とは関係ありません。
- **販売登録はしていません。** 販売中の58作品（Motion Kit など本番商品）とは別管理です。購入・決済の導線はありません。
- 各ページは静的なHTML/CSS/JSのみで、外部URLの読み込み・計測タグ・外部フォントは含みません。

## 権利・素材について

- 見本内の文章・数値・店名はすべて架空のものです。
- 参考にした外部素材がある場合は、各権利者の条件に従います。本リポジトリ全体に対する再利用ライセンス（MIT等）は付与していません。
