「なんとなく滑らか」を、
数字で説明する。

動きの良し悪しは、開始から終了までの配分でほぼ決まります。kine はその配分を、言葉ではなくカーブで共有します。

01 / CURVE

曲線が主役

始まりは速く、終わりは静かに。0.2 秒の差が、重さの印象を変えます。

02 / KEY

キーは3つまで

増やすほど制御は難しくなる。まず3つの点で、伝えたい順番を決めます。

03 / LOOP

止め方も設計

繰り返す動きには、必ず静止の間を。目が休める場所を残します。

決めた動きは、
そのまま渡す。

タイムラインの値は、CSSの変数として書き出せます。実装側で秒数を測り直す必要はありません。

  • イージング名と秒数をセットで記録
  • キー位置は % で保持
  • 動きを減らす設定では自動で静止
motion.css
/* 0.8s / ease-out */
.hero {
  --motion-duration: .8s;
  --motion-ease: cubic-bezier(.22,.61,.36,1);
  --motion-distance: 26px;
}
@media (prefers-reduced-motion: reduce) {
  .hero { --motion-distance: 0px }
}
